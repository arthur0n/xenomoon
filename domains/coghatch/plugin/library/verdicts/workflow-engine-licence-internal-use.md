The self-hosted workflow engine's licence is accepted for internal use with no obligation; offering it to clients as a service needs a licence review first.

## Why

- Internal use does not trigger the service-offering clause.
- The runbook carries the note so the review is not skipped if the use changes.
- This is a reading of the licence text, not legal advice.

## Context

Accept the licence reading: the server is used internally only, so no obligation applies. Offering the
server across clients as a service requires a licence review before it happens.

The self-hosted Inngest server is under SSPL v1.0. SSPL places obligations on anyone offering the software
as a service to third parties.
